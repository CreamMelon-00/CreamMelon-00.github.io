# 형식:  어록: 대사 | 출처메모

#   - '|' 뒤의 출처메모는 편집용이라 화면에 표시되지 않는다.
#   - '#'로 시작하는 줄은 주석.
#
# 화자와 출처를 감추는 게 이 기능의 핵심이다 — 아직 안 읽은 사람을 끌어들이는
