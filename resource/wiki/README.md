# 위키 이미지

`lore/` 문서의 `이미지:` 항목이 가리키는 자리다. 파일 이름을 문서 제목과 똑같이 맞춰 이 폴더에 넣으면 인포박스에 바로 나온다. 없으면 점선 자리만 표시되고, 어떤 파일을 넣어야 하는지 경로가 적혀 있다.

- 이름 규칙: `<문서 제목>.png` — 예) `노에시스.png`, `그렌빌리아 대륙.png`
- 넣은 뒤에는 `python tools/build_wiki.py` 를 다시 돌린다.
- png 외에 jpg·webp·svg도 된다. 문서의 `이미지:` 경로만 확장자에 맞춰 고치면 된다.
- 본문 중간에 넣을 이미지는 마크다운으로 쓴다: `![설명](resource/wiki/파일.png)`

경로는 저장소 뿌리 기준으로 적는다. 뷰어가 `wikipage/` 안에 있으므로 `../` 는 뷰어가 알아서 붙인다.
