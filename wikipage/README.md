# 세계관 아카이브

설치 없이 브라우저에서 실행하는 개인용 세계관 위키 편집기입니다.

## 실행 방법

1. 압축 파일을 풉니다.
2. `index.html`을 Chrome, Edge, Firefox 등의 브라우저로 엽니다.
3. 첫 실행 시 예시 문서가 생성됩니다.

## 주요 기능

- 문서 생성, 하위 문서 생성, 복제, 삭제
- 폴더, 상위 문서, 정렬 순서와 속성 관리
- Markdown 편집과 실시간 미리보기
- `[[문서 제목]]` 내부 링크
- 역링크 표시
- 제목, 본문, 속성 통합 검색
- 시대, 정사 등급, 작업 상태, 태그, 검토 메모
- 현재 문서 Markdown 내보내기
- 전체 프로젝트 JSON 백업과 복원
- 다크·라이트 테마
- 모바일 대응

## 단축키

- `Ctrl+S`: 즉시 저장
- `Ctrl+K`: 문서 검색
- `Ctrl+N`: 새 문서
- `Ctrl+Shift+N`: 선택한 문서의 하위 문서

macOS에서는 `Ctrl` 대신 `Command`를 사용할 수 있습니다.

## 저장과 백업

작성 내용은 현재 브라우저의 로컬 저장소에 자동 저장됩니다. 브라우저 데이터 삭제나 다른 컴퓨터로의 이동에 대비해 상단의 `프로젝트 백업` 버튼으로 JSON 파일을 정기적으로 저장하십시오.

## 내부 링크

```md
[[노에시스]]
[[미트로프 연방|연방]]
[[연말 위기#결과]]
```

존재하지 않는 링크를 미리보기에서 누르면 새 문서를 만들 수 있습니다.

## 파일 구성

- `index.html`: 실행 파일
- `README.md`: 사용 안내
- `sample_project.json`: 가져오기 테스트용 예시 백업

이 버전은 외부 서버와 라이브러리를 사용하지 않는 1차 프로토타입입니다.

## 문서 계층과 정렬

- 왼쪽 문서 목록에서 같은 상위 문서를 가진 문서끼리 드래그하면 순서가 바뀝니다.
- 오른쪽 `정렬 순서`에 숫자를 직접 입력할 수도 있습니다. 숫자가 작을수록 위에 표시됩니다.
- `하위 문서` 버튼은 현재 선택한 문서를 상위 문서로 지정하여 새 문서를 만듭니다.
- 오른쪽 `상위 문서` 선택 상자에서 기존 문서의 계층을 변경할 수 있습니다.
- 상위 문서를 삭제하면 그 하위 문서는 한 단계 위로 이동하며 삭제되지 않습니다.
